## ▍whoami

I build backend systems, small developer tools, and the occasional interface that has no business looking as good as it does. Most of my work starts the same way — I hit a rough edge in something I use daily, decide the abstraction is worse than it needs to be, and write a thinner one.

`mongocli` came out of exactly that: PyMongo is powerful and verbose, so I wrapped the parts I actually reach for into something that reads like a sentence. Lately I'm spending time on streaming architecture and on making my tooling boring enough to disappear.

```python
class Arsh:
    def __init__(self):
        self.role     = "Software Developer"
        self.focus    = ["backend systems", "developer tooling", "automation"]
        self.building = ["velura-streaming-platform", "mongocli"]
        self.learning = ["system design", "performance profiling"]

    def philosophy(self) -> str:
        return "Make it work, make it readable, then make it fast."
```
